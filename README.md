# CrystalGacha
Github repository for Crystal Gacha Minecraft mod.

Los Gachas tienen una carga base de 0 y una pureza base de 100. Por cada alimento que ingieran, estos valores cambiaran. Una vez consigan una carga de 50 o mas, soltan un cristal. La rareza de este cristal dependera del nivel de pureza que tenga el gacha al momento de soltar el cristal. A continuacion las tablas de valores.

Tabla de carga y pureza para cada rareza.
Rarity   | Charge | Purity
Commom   |   +1   |   -3
Uncommon |   +3   |   -2
Rare     |   +5   |   -1
Epic     |   +7   |   -0

Tabla de keke
Purity | Rarity   | Random Chance
>= 91  | Epic     | 2%
>= 67  | Rare     | 12%
>= 30  | Uncommon | 28%
<= 29  | Common   | -
